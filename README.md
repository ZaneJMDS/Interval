# Interval

2D platformer where you play as \_\_ and try to reach the fruit. Luckily you can change gravity



Controls:

Movement:

A, <: Move Left

D, >: Move Right

W, Space, ^: Jump

S, <Down arrow>: Fall



Special:

G: Change gravity direction

R: Reset level
